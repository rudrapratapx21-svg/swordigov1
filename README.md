# Shadowbound: The Lost Kingdom — V2

A more complete original dark-fantasy browser RPG built with HTML5 Canvas, CSS3 and vanilla JavaScript modules.

## Run
Open `index.html` in a modern browser.

## Controls
A/D or Arrow Keys — move
Space/W/Up — jump
J — sword
K — magic
E — interact
I — inventory
Esc — pause

No external game engine or copyrighted game assets are used.
